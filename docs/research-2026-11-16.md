## Implementation choice

The project checks the effective OpenAPI path parameter set, follows supported local references, applies documented path styles, and compares exact rendered request paths against fixtures. Its reference points are OpenAPI's path inheritance rules and RFC 6570 percent-encoded expansion. It runs locally with synthetic examples and a loopback HTTP test.
